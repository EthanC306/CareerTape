# CareerTape
A full stack application for career fairs and networking opportunities allowing the users to upload the employers with an AI system that ranks these employers against your resume. The application helps you get to know the company, provides you with questions to ask, allows you to add messages about who you talked to at that company, and send follow ups to those recruiters. This app is currently in an early demo. 

## Tech Stack
| Layer | Technology |
|---|---|
| **Frontend** | React 19 and TypeScript |
| **Framework** | Vinext with Next.js-compatible routing |
| **Styling** | Tailwind CSS 4 |
| **Components** | Shadcn UI, Base UI, and Lucide icons |
| **Backend** | TypeScript API routes running in a Cloudflare Worker |
| **Database** | Cloudflare D1 serverless SQLite |
| **ORM** | Drizzle ORM |
| **Validation** | Zod |
| **Hosting** | OpenAI Sites on Cloudflare infrastructure |
| **Local Tooling** | pnpm, Vite, and Wrangler |
| **AI Integration** | WebMCP tools exposing application actions to compatible AI agents |
